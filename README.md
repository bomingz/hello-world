# Hello, world

A minimalist static site, published with GitHub Pages.

- [Homepage](https://bomingz.github.io/hello-world/)
- [Ellie’s Random Mood](https://bomingz.github.io/hello-world/ellies-random-mood/): a playful game with four abstract emoji, a random mood button, and switchable Farm Friends and Ocean Pals worlds.

## Local preview

Run `python3 -m http.server 8765` in this directory, then open `http://localhost:8765/`.

The game needs no build tools, accounts, or backend. It supports keyboard input and reduced motion. The generated artwork lives in `ellies-random-mood/assets/`; its built-in image_gen prompts are recorded in [docs/emoji-prompts.md](docs/emoji-prompts.md). The reference photo is not included in the repository.
